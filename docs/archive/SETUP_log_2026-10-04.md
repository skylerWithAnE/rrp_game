## Remaining steps

1. Finish installing Unity Hub and a Unity 6 LTS editor.
2. Create the Unity project **inside `rrp_game`**. The folder already contains `.git`, `.gitignore`,
   `CLAUDE.md` and `docs/`, so Unity Hub may refuse to create a project there. Options:
   - have Claude create it from the command line
     (`Unity.exe -batchmode -quit -createProject <path>`), then switch it to URP, or
   - create it elsewhere in Hub with the URP 3D template and move `Assets/`, `Packages/`,
     `ProjectSettings/` into `rrp_game`.
3. In Unity: *Window > Package Manager > + > Add package from git URL*:
   `https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity`
4. In Unity: *Window > MCP for Unity*, start the server, choose **Claude Code**, click Configure.
5. Open a new terminal (so `uv` is on PATH), `cd` into `rrp_game`, run `claude`, then `/mcp` to
   confirm the Unity server is connected. Unity must be open with the project loaded.
6. Make the first commit.
7. Add multiplayer packages when milestone work reaches them (see `TECH_PLAN.md` section 3).
