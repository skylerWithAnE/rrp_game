# Archive

Superseded planning documents from the first design conversation (2026-10-04), kept for reference
only. They are the long versions as they stood just before the docs were trimmed to decided scope.

**Do not treat anything here as current.** These files contain ideas that were later cut, deferred
or replaced (the railroad, chip seal, hot asphalt, the rumble meter, the long dig-up list, a 2 km
map, and more). The current design is in `docs/DESIGN.md`, `docs/TECH_PLAN.md` and `docs/SETUP.md`.

| File | What it was |
|---|---|
| `DESIGN_full_2026-10-04.md` | Full design doc: every idea discussed, the road variants, the tier-by-tier crew plan, dig-up ideas, decision log, railroad history |
| `TECH_PLAN_full_2026-10-04.md` | Full technical plan, including the voxel versus heightfield and deterministic physics discussion |
| `SETUP_log_2026-10-04.md` | Setup log as it stood before the Unity project was created |
| `CLAUDE_2026-10-04.md` | The earlier `CLAUDE.md` |
| `PLAN_draft_2026-10-04.md` | Draft build plan written in plan mode; its milestone list was superseded |
| `POSTMORTEM_badscale.md` | Post-mortem of the first prototype (third person, physics cubes), rejected 2026-10-04 for its scale, camera and verbs |
| `TECH_PLAN_badscale.md` | The first prototype's technical plan, as built through milestone 6 |
